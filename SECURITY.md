# Sicherheitslücken melden

Bitte eine Lücke nicht als öffentliches Issue melden, sondern vertraulich: im Reiter **Security** dieses
Repos auf **Report a vulnerability** (GitHub Private Vulnerability Reporting). Die Meldung sehen nur die
Betreuer des Repos.

Hilfreich sind: was betroffen ist, wie es sich nachstellen lässt und was ein Angreifer damit erreicht.
Bitte keine echten Daten von Personen mitschicken.

Gepflegt wird nur der aktuelle Stand von `main`.
